# kharkovskykvLab
## Bank
###  Вторая лабораторная работа
    В коде автоматически инициализировать 5 разных банков, у каждого банка
    должно быть:
    • минимум 3 банкомата
    • минимум 3 банковских офиса
    В каждом банковском офисе должно работать не менее 5 сотрудников
    • минимум 5 клиентов
    У каждого клиента должно быть:
    • минимум 2 платежных счета
    • минимум 2 кредитных счета
    Должна быть опция вывода всех данных по банку (банкоматы, офисы,
    сотрудники, клиенты) в консоль. У каждого клиента должна быть опция
    вывода всех его счетов в консоль.
